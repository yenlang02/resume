MIPS Single-Cycle CPU Simulator

Description

Implemented a simplified MIPS processor simulator in C, modeling the instruction execution cycle including fetch, decode, execute, memory access, and write-back stages.

Skills Learned

  • Understanding MIPS instruction execution cycle (fetch, decode, execute, memory, write-back)
  • Bit manipulation using shifts and masks
  • Designing an Arithmetic Logic Unit (ALU) with arithmetic, logical, comparison, and shift operations
  • Implementing ALU control logic based on opcodes and function codes
  • Programming in C
